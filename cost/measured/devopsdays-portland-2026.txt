  * Each account's billed usage (Cost Explorer record type Usage, unblended) on the window's UTC days. It is
    measured, not estimated, and it is the whole account: a co-tenant's spend on the same days is inside it.

    payer is the lab-account provider's, which is not asked (#392). It is printed so the day the tags are
    active, the per-delivery figure is in this report without a code change.
